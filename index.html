Living Research / Field Guide

From Chatbots to Autonomous Workers

A human-friendly roadmap for understanding, building, and deploying agentic AI systems — whether you're a beginner exploring the idea or an engineer wiring up multi-agent swarms.

● 6 Stages ● 3 Patterns ● 5 Frameworks ● Updated May 2026
01

The 6 Stages

Each stage adds a new capability. You don't need to jump to the end — most real-world value today comes from Stage 3 and 4.

01

Chatbot

Passive Q&A — you ask, it answers. No tools, no memory, no action.

▼
You → "What's the weather?" → AI → "72°F and sunny."

The simplest form. A single prompt in, a single response out. Think ChatGPT in basic mode, or a customer support FAQ bot.

For Beginners

  • Start with ChatGPT, Claude, or Gemini
  • Learn prompt engineering basics
  • Experiment with role prompts

Engineer Details

  • Single-turn inference via REST API
  • Context window management
  • System prompts & temperature tuning
02

Copilot

AI assists — you stay in the driver's seat. Real-time suggestions.

▼
You ↔ Copilot + IDE / Doc

The AI works alongside you. GitHub Copilot suggests code as you type. Notion AI rewrites paragraphs. You approve every change — the AI never acts alone.

For Beginners

  • Try GitHub Copilot or Cursor IDE
  • Use Notion AI or Google Docs AI
  • Think "assistant," not "replacement"

Engineer Details

  • Inline completion APIs (streaming SSE)
  • Context injection from current file/project
  • Latency-critical: <300ms to feel instant
03

Agent

AI picks a tool and completes the task. This is where "agentic" begins.

▼
Goal → Agent ⚡ Tool → Result

You give a goal, the AI reasons, picks the right tool, executes, and returns a result. It can browse the web, query a database, or run code — all without micromanagement.

For Beginners

  • Try ChatGPT with Code Interpreter
  • Use Perplexity for research with sources
  • Build a simple Zapier + OpenAI flow

Engineer Details

  • ReAct pattern: Reason → Act → Observe
  • Tool schemas (OpenAI function calling)
  • Loop until task complete or max iterations
  • Key: LangChain, OpenAI Agents SDK
04

Multi-Agent Team

Specialized agents hand off work to each other.

▼
Researcher → Writer → Editor → Final Doc

Instead of one generalist, you have a team. A researcher gathers data, a writer drafts, an editor polishes. Each has a role, tools, and memory. A supervisor routes tasks between them.

For Beginners

  • Try CrewAI with pre-built crews
  • Define 2-3 clear roles with backstories
  • Start linear, add loops later

Engineer Details

  • Supervisor pattern: central router + workers
  • LangGraph for cyclic / conditional flows
  • Shared state / scratchpads between agents
  • Human-in-the-loop interrupts
05

Agent Swarm

Agents debate, review, and self-correct to find the best answer.

▼
Proposer Critic Fixer Judge Best Answer

Multiple agents compete or collaborate to find the best answer. One proposes, another critiques, a third fixes, and a judge picks the winner. Quality goes up; cost goes up linearly.

For Beginners

  • AutoGen group chats feel like Slack debates
  • Set up a "red team" to challenge answers
  • Use for high-stakes: strategy, code review

Engineer Details

  • Debate pattern: generate → critique → revise
  • Consensus: voting, confidence scoring
  • AutoGen GroupChat with selector
  • Cost explodes with agent count — use sparingly
06

Autonomous Organization

AI workers managing other AI workers. Minimal human oversight.

▼
Planner → 5 Workers → Evaluator ↻ Planner

The AI designs its own org chart. A planner breaks goals into subtasks, delegates to workers, evaluates results, and replans if needed. Humans set the mission; the system handles execution.

For Beginners

  • Not production-ready for most yet
  • Best for R&D, content pipelines, codebases
  • Requires strong observability and kill-switches

Engineer Details

  • Meta-agent: agent that creates agents
  • Hierarchical planning with HTNs
  • Self-evaluation loops + reward models
  • Observability: LangSmith, W&B, OpenTelemetry
02

Orchestration Patterns

How you wire agents together matters more than how smart each one is. These are the three dominant patterns in production.

🎯

Supervisor

A central supervisor receives the request, breaks it into subtasks, and delegates to specialized worker agents. The supervisor validates outputs and synthesizes the final answer. Most common production pattern — simple and debuggable.

⚡

Debate / Critic

One agent proposes, another critiques, a third revises. Repeat until consensus or max rounds. Used for high-stakes tasks like code review, strategy, or medical reasoning. Quality goes up; cost goes up linearly.

🐝

Swarm

Many lightweight agents work in parallel on subtasks, then aggregate results. Great for search, data collection, or brute-force exploration. Think MapReduce but with reasoning agents.

03

Frameworks

Pick the framework that matches your team's skill level and the complexity of your workflow.

Beginner

CrewAI

Rapid prototypes, role-based teams, readable configs. YAML-like agent definitions that non-engineers can understand.

Pattern: Role-based crew
Engineers

LangGraph

Cyclic workflows, branching logic, heavy observability. Best for complex stateful flows that need human-in-the-loop.

Pattern: Graph nodes = agents
Conversational

AutoGen

Group chats, debates, consensus-building. Agents talk to each other like colleagues in a Slack thread.

Pattern: GroupChat + selector
Minimal

OpenAI Agents SDK

Thin wrapper, raw control, OpenAI-native. No heavy abstractions — just agents, tools, and handoffs.

Pattern: Agent + handoffs
Experimental

Google ADK

Google Cloud shops, Vertex AI integration. Early but tightly integrated with Google's ecosystem.

Pattern: Multi-agent + tools
04

MCP & Tools

Model Context Protocol

Think of MCP as "USB-C for AI tools." Introduced by Anthropic in late 2024, it's an open standard that lets any AI agent securely connect to any data source or tool — your filesystem, a database, Slack, GitHub, or a browser — without custom integrations for each pair.

Instead of writing a new connector for every tool, you build (or use) an MCP server once, and any MCP-compatible agent can plug into it. This is what made production-grade agents actually possible in 2025.
